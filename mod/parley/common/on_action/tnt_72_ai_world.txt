#   The hard bound is NOT the chance — it is tnt_ai_world_cd, the three-year lock

#   CONCLUDED TREATIES A YEAR ACROSS THE WHOLE MAP at `rare`, and 15 to 40 at
#   `common`.
#   Those are ESTIMATES, not measurements: the balance pass-rate depends on the
#   actual distribution of incomes, opinions and personalities in the save, which
#   nothing static can predict. The knob is
#   tnt_ai_world_chance_value (tnt_56_ai_values.txt part 8) and it is one value.

#   *** THE QUOTED RATES WERE CALIBRATED FOR TWO HOSTS, AND THE LADDER WAS
#   DOUBLED WHEN HOST 2 WENT (2026-08, same commit). *** Two hosts meant an
#   effective annual chance of 1-(1-p)^2 (at p = 0.14 that is 0.26); one host

# tnt_ai_world_pulse
#
# Root = an AI count-or-above, once a year on their birthday, reached through
# ai_character_pulse (the sole host since 2026-08). Everything below is a gate;
# the work is in MOD\common\scripted_effects\tnt_38_ai_world.txt E11.
#
# ===========================================================================
# THE TRIGGER, ROW BY ROW, IN DELIBERATE COST ORDER
# ===========================================================================
# CHEAPEST AND MOST SELECTIVE FIRST. This trigger runs ~700 times a year for every
# save in existence, including saves whose owner has the rule switched off, so the
# first row has to be the one that ends the conversation for those saves.
#
#  1. NOT has_game_rule tnt_ai_treaties_off
#     One flat lookup, and for a user who does not want silent AI treaties it is the
#     ONLY row that ever runs. Everything downstream — including
#     tnt_ai_world_chance_value's own belt-and-braces `off` multiply — is then
#     unreachable.
#     `has_game_rule = <SETTING id>`, not the rule id. REAL:
#       GAME\common\character_interactions\00_culture_interactions.txt:181
#         (has_game_rule = less_common_hybrid_culture_ai_frequency)
#       GAME\common\character_interactions\00_adoption.txt:16 (has_game_rule = no_adoption)
#     Rule and settings: MOD\common\game_rules\tnt_81_ai_rules.txt.
#
#  2. is_ai = yes
#     Belt-and-braces since host 2 went (2026-08): the one remaining host is
#     already is_ai-gated by vanilla (yearly_on_actions.txt:2870-2872). The row
#     STAYS because it is one flat lookup and it is the only thing standing
#     between a future player-inclusive re-host (the W-7 recovery in the header)
#     and the single worst failure this feature could have: the player silently
#     brokering treaties on his own behalf with no window, no consent and no
#     notification.
#     REAL: GAME\common\character_interactions\00_gift.txt:499.
#
#  3. is_landed = yes  /  is_ruler = yes
#     An unlanded character has no income to price a treaty against, no realm to
#     make a truce meaningful and nothing any of the five allowed items can move.
#     REAL: GAME\common\character_interactions\00_character_interactions.txt:26
#     (is_landed, offer_vassalization is_shown);
#     GAME\common\character_interactions\00_alliance.txt:1124, :1127 (is_ruler).
#     Vanilla's own reason for pairing them on a hot on_action, verbatim:
#       GAME\common\on_action\health_on_actions.txt:291
#         is_ruler = yes # For performance reasons we limit this as checking modifiers is expensive
#
#  4. highest_held_title_tier >= tier_county
#     THE BARONY CUT. 265 of the 271 vanilla ai_frequency_by_tier blocks set
#     `barony = 0`, i.e. vanilla switches barons out of AI diplomacy entirely
#     (43-…md §1.8, measured). yearly_playable_pulse is count+ already, so on that
#     host this is redundant; ai_character_pulse's own trigger is only `is_ai = yes`,
#     so on host 1 it is not. It also makes tnt_ai_world_chance_value's ladder total:
#     a character below county gets 0 from it and would waste the pick anyway.
#     tier constants: GAME\common\script_values\00_title_tiers_values.txt:1-7.
#
#  5. is_at_war = no
#     A ruler fighting for his life is not brokering side-treaties, and this is also
#     where the AI's own decision budget is busiest. It is vanilla's own first line
#     in this position — GAME\common\character_interactions\00_courtier_and_guest_interactions.txt:168
#       is_at_war = no # Try to avoid wasting your war chest!
#     and GAME\common\character_interactions\00_culture_interactions.txt:123 inside
#     ai_cultural_hybridization_interaction's ai_potential, which is the closest
#     vanilla analogue of this whole pulse.
#     NOTE: the CANDIDATE is also required to be at peace (tnt_38_ai_world.txt E11).
#     Until USER ITEM 26 a mid-war TRUCE stayed reachable through phase B, where a
#     human sees the offer; the door now refuses an at-war pair outright
#     (tnt_10_interaction.txt is_valid), so the one phase-B seam left is a war
#     declared while the window is already open. T13 still carries no at-war row —
#     its header (tnt_40_triggers.txt) explains why. The silent path never did.
#
#  6. NOT has_variable tnt_ai_world_cd
#     The three-year lock from E10. One lookup. (The old text here credited it
#     with making double-hosting idempotent; the 2026-08 log disproved that for
#     the same-tick case — fire2's trigger did not see fire1's variable — which
#     is part of why host 2 was deleted rather than latched.)
#
#  7. tnt_not_the_watch_trigger = { WHO = this }        V15, USER ITEM 3
#     THE WALL BROKERS NOTHING, SILENTLY OR OTHERWISE. This is the PROPOSER half
#     of the pair rule whose RECIPIENT half is the same call inside E11's
#     candidate limit (tnt_38_ai_world.txt) — both halves are needed, because a
#     Watch ruler otherwise still pulses, picks a partner and composes a treaty.
#     Last measured as an ACTOR in the 2026-08-16 run (the S-FEALTY entry's own
#     note records the Lord Commander in the a= role); the 2026-08-17 run happened
#     to show him only as b=, so the role is reachable and merely unmeasured this
#     time. ONE flat government lookup, ~700 evaluations a year, ALWAYS TRUE in a
#     vanilla-only game — the whole safety proof is in T48's header,
#     MOD\common\scripted_triggers\tnt_40_triggers.txt. It also refuses AGOT's
#     ruins/unknown/wilderness placeholder governments through T48's second flag.
#     It sits LAST because it is the least selective of the seven, and the cost
#     table above gains one flat lookup on the trigger rows.
#
# WHAT IS **NOT** IN THE TRIGGER, AND WHY
#   * basic_is_valid_for_yearly_events_trigger. It is the standard guard for
#     pulse-hosted EVENTS (GAME\common\scripted_triggers\00_available_for_events_triggers.txt:767-781,
#     used by random_yearly_playable_pulse at yearly_on_actions.txt:2525-2527), and
#     PDX's note at :783 is a warning about exactly this: "It's a lot better for
#     performance to not have scripted triggers within scripted triggers when they're
#     checked as often as these ones are." We fire no event and open no window, so
#     none of what it tests (imprisoned, incapable, travelling, in an activity)
#     changes whether two AI treasuries can exchange gold. The two rows of it that
#     WOULD matter — alive and landed — are already above, flat.
#   * A partner test of any kind. There is no partner yet; picking one is E11's job
#     and it is behind the probability gate, which is the whole point of the split.
#   * The probability gate itself. It lives in the effect because
#     tnt_ai_world_chance_value needs `scope:actor`, and the trigger has no saved
#     scopes. Putting it here would mean a second value family keyed on root.
#
# THE EFFECT IS ONE SYNCHRONOUS CHAIN. The strategic submission lane runs first;
# only a success writes the shared cooldown, so the ordinary E11 lane remains the
# fallback without a second queued host or a same-tick double deal. Everything
# real is in tnt_38_ai_world.txt, including the scope and D4 analyses.
###############################################################################
tnt_ai_world_pulse = {
	trigger = {
		NOT = { has_game_rule = tnt_ai_treaties_off }
		is_ai = yes
		is_landed = yes
		is_ruler = yes
		highest_held_title_tier >= tier_county
		# All silent realm mutations require peace. In particular, never change a
		# liege during AGOT's temporary Mega-War independence graph.
		is_at_war = no
		NOT = { has_variable = tnt_ai_world_cd }
		# AGOT SUSPENDED (CK3 1.20): compatibility guard parked; awaiting the AGOT update.
		# tnt_not_the_watch_trigger = { WHO = this }		# V15, USER ITEM 3: the Wall brokers nothing, silently or otherwise. See T48, tnt_40_triggers.txt, and row 7 of the list above.
	}

	effect = {
		# One synchronous chain. A successful strategic submission writes the
		# three-year cooldown before the generic fallback is considered, avoiding
		# the same-tick double-dispatch defect measured for the retired second host.
		tnt_ai_world_submission_pulse_effect = yes
		if = {
			limit = {
				NOT = { has_variable = tnt_ai_world_cd }
			}
			tnt_ai_world_pulse_effect = yes
		}
	}
}
