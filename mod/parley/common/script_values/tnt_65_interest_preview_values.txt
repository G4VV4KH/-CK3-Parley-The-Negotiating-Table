# Display-only interest previews. NEVER referenced by settlement, AI or legality.
# Table-owner scope, current evaluator var:tnt_partner; no cached participant.
# All original selected factors, weighted amounts and percent APIs stay intact.
#
# Currency preview is the one-sided marginal rate at CURRENT stock/capacity:
# receive: 100 below C, 100/(1+s) at C..2C, 0 at/above 2C;
# surrender: 100 above C, 100/(1+s) at C/4..C, 100/(1+3s) at/below C/4.
# This is not an invented selected quantity, affordability, or a settled price.
# Influence previews follow the same bilateral government guard as actual ratios.
#
# Empty title/subject preview assumes ONE hypothetical county/direct vassal and
# ignores other draft legs; courtier assumes ONE recruit. Object identities,
# price/skills/kinship/de-jure and legality are not guessed. Artifact preview uses
# the existing category baseline, excluding unknown slot/equipped-object axes.
# Other terms reuse ONLY existing participant-context raw motives.
# Signed contract zero previews explicitly mean the RECEIVING/BENEFIT baseline;
# no selected direction or signed price is asserted until a real delta exists.
#
# *_preview_percent_value: descriptive unrounded preliminary percentage.
# *_display_percent_value: original selected percentage, otherwise preview.
# *_badge_percent_value: the display result rounded ONCE for text AND color.
# Off/missing rule or absent partner: 100; missing partner is unavailable context,
# not a genuine computed 100 (GUI must still gate on partner validity).
# No threats, called-in hooks, effect/variable mutation, selection or price writes.
