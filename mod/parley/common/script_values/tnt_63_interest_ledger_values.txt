# whole-deal preflight still validate both gross legs; no permission is granted
# by netting. Original gross totals remain the physical/stress accounting API.
# Pressure (threats and called-in hooks) never enters these interest formulas.
# Off dispatches to legacy values before evaluating any new contextual input.
